# 🔤 Anagram Game

A simple and interactive **Anagram Game** built using **HTML, CSS, and JavaScript**.
The user needs to rearrange the given letters and find the correct word.

## 📌 Features

* 🔤 Displays scrambled letters
* ✍️ Allows the user to enter their answer
* ✅ Checks whether the answer is correct
* ❌ Shows an error message for incorrect answers
* 🔄 Option to try another word
* 🎨 Simple and responsive user interface
* ⚡ Built using pure JavaScript

## 🛠️ Technologies Used

* **HTML5** – Creates the structure of the game
* **CSS3** – Provides styling and responsive design
* **JavaScript** – Handles game logic and user interaction

## 🎮 How to Play

1. Open the Anagram Game.
2. A word will be displayed with its letters shuffled.
3. Rearrange the letters mentally.
4. Enter the correct word in the input box.
5. Click the **Check** button.
6. The game will tell you whether your answer is correct or incorrect.
7. Try another word and continue playing.
